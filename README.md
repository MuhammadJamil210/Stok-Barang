# Sistem Informasi Stok Barang

## Deskripsi
Sistem Informasi Pencarian dan Pemantauan Stok Barang merupakan aplikasi yang dirancang untuk membantu pemilik toko dan petugas dalam mengelola persediaan barang secara lebih mudah, cepat, dan teratur.

## Tujuan
- Mempermudah pencarian barang.
- Memantau jumlah stok barang.
- Membantu pencatatan transaksi penjualan.
- Memperbarui stok secara otomatis.
- Mengurangi kesalahan pencatatan persediaan.

## Fitur Utama
- Pengelolaan data barang.
- Pencarian barang berdasarkan nama.
- Transaksi penjualan.
- Pembaruan stok otomatis.
- Pencatatan barang masuk.
- Peringatan stok menipis dan habis.
- Riwayat transaksi.

## Teknologi
- PHP
- Pemrograman Berorientasi Objek (PBO)
- SQLite atau MySQL
